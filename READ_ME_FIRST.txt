This zip holds every app file. Upload all of them (everything except this READ_ME) to your GitHub repository:
  GitHub > fotc-checkin > Add file > Upload files > drag all the files in > Commit changes.
NEW files: pipeline.py (automatic transcribing and tagging), answers.py, launch.py, transcribe.py.
After uploading you can delete tagging.py from GitHub (it is replaced by answers.py).
Check that no file has "(1)" or "(2)" in its name. Then Manage app > Reboot app.
Sign in as admin > Settings: check the status lines for transcription and tagging, set both "automatically" options to Yes, then Save.
