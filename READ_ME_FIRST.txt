This zip holds every app file. Upload all of them (everything except this READ_ME) to your GitHub repository:
  GitHub > fotc-checkin > Add file > Upload files > drag all the files in > Commit changes.
NEW files: answers.py, launch.py, transcribe.py.
After uploading you can delete tagging.py from GitHub (it is replaced by answers.py). Open the file, click the three dots, Delete file.
Check that no file has "(1)" or "(2)" in its name. Then Manage app > Reboot app.
Sign in as admin and open Settings. Check Program stage, then Save.
To turn on automatic transcription, see Settings > "How to set up automatic transcription".
